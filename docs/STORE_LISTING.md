## Permission and policy declarations (Play Console → App content)
Copy these explanations into the declaration forms.

**Exact alarms (`USE_EXACT_ALARM`)** — core feature
> The app is a prayer-time reminder. Muslims pray at precise times of day, so the app must start the adhan alarm at the exact minute of each prayer, also when the app is closed. This is the main purpose of the app, not an optional feature.

If Play rejects `USE_EXACT_ALARM` for this category, remove that one line from `AndroidManifest.xml`; the app still works with the user-granted `SCHEDULE_EXACT_ALARM` (Settings has a shortcut to allow it).

**Foreground service type: Media playback** (`FOREGROUND_SERVICE_MEDIA_PLAYBACK`)
> When a prayer time arrives the app plays the adhan (an audio recording of up to a few minutes). A foreground media-playback service with a notification (Pause / Resume / Stop buttons) keeps the audio playing when the screen is off or the app is in the background. The user can stop it any time from the notification. Task: "Play adhan audio at prayer time".
*(Play may ask for a short screen recording: record a prayer time arriving with the app closed — use Settings → Adjust times to move a prayer to 2 minutes from now.)*

**Boot completed (`RECEIVE_BOOT_COMPLETED`)** — to set the next prayer alarm again after the device restarts.
**Notifications (`POST_NOTIFICATIONS`)** — prayer-time message and adhan controls.
**Wake lock** — keeps the adhan from being cut off while it plays.
